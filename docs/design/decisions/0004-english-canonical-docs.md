# ADR 0004: English Canonical Docs

## Status

Accepted.

## Decision

Design and implementation documents are written in English as the canonical source.

## Context

The documents will be consumed by many coding agents. English technical terms reduce ambiguity and improve model consistency.

## Consequences

- Vietnamese summaries may be added for human review, but they do not override English docs.
- Code identifiers and prompt schema names should follow the English docs.
